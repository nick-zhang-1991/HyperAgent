Quickstart

Get started with HyperAgent in 5 minutes.

1. Start the REPL

$ hyper ╔══════════════════════════════════════════════╗ ║ HyperAgent Interactive Shell ║ ╚══════════════════════════════════════════════╝ Directory: /Users/me/my-project Provider: deepseek-v4-flash Memory: 71 past learnings Commands: /exit /help /clear /stats /memory /reindex hyper>

2. Ask Questions

Just type naturally — HyperAgent auto-detects whether you're asking or commanding:

hyper> 分析这个项目的架构 📋 Planning... 💬 这个项目使用 Rust + React 架构，核心模块包括...

3. Fix Bugs

hyper> Fix the off-by-one error in sum_range 📋 Planning... Plan: Fix off-by-one by changing start..end to start..=end in src/lib.rs 1. Change range to inclusive in src/lib.rs 👨‍💻 Executing...

4. Add Features

hyper> Add email validation to the User model in src/models/user.rs

5. Check Code Health

hyper> /health

6. Manage Teams

hyper> /org init "My Company" admin@company.com hyper> /org team add dev@company.com

7. Schedule Tasks

hyper> /schedule add "0 9 * * 1" "Run health check" hyper> /schedule list
