Cline Integration

Connect HyperAgent to Cline — the most popular VS Code AI coding extension (20,000+ users).

What This Gives You

  • Use HyperAgent's 4 MCP tools directly from Cline's VS Code panel
  • Search code, explain functions, get code stats, and list symbols
  • No need to switch between terminals — stay in your editor

Setup

Add this to your Cline MCP settings (cline_mcp_settings.json):

{ "mcpServers": { "hyperagent": { "command": "hyper", "args": ["mcp-server"], "disabled": false, "autoApprove": [] } } }

Quick Import

Or copy our pre-configured file:

cp packages/vscode/cline-mcp.json ~/.config/Code/User/globalStorage/rooveterinaryinc.roo-cli/settings/cline_mcp_settings.json

Available Tools

ToolDescription
search_codeSearch the codebase by symbol name or pattern
explain_codeGet explanation of a function or file
code_statsGet statistics about the codebase
list_symbolsList all symbols in a file

Requirements

  • HyperAgent installed (curl ... | bash)
  • Cline VS Code extension installed
  • hyper available in PATH
