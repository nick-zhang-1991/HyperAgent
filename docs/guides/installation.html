Installation

HyperAgent is distributed as a single static binary with zero runtime dependencies.

Prerequisites

  • macOS 10.15+, Linux (x86_64), Windows 10+
  • An LLM API key (DeepSeek, OpenAI, Anthropic, or OpenRouter)
  • Git (for version control integration)

Quick Install (macOS/Linux)

curl -fsSL https://raw.githubusercontent.com/nick-zhang-1991/HyperAgent/master/scripts/install.sh | bash

Homebrew (macOS)

brew tap nick-zhang-1991/hyperagent
brew install hyperagent

npm (experimental)

npm install -g hyperagent-cli

From Source

git clone https://github.com/nick-zhang-1991/HyperAgent.git
cd HyperAgent
cargo build --release
cp target/release/hyperagent /usr/local/bin/hyper

Verify Installation

hyper --version
hyper help

Configuration

On first run, HyperAgent will prompt you to configure an LLM provider. You can also set environment variables:

export HYPER_LLM_API_KEY="sk-your-key-here"
export HYPER_LLM_BASE_URL="https://api.deepseek.com/v1"

# Or create ~/.hyper/config.toml:
[provider]
api_key = "sk-your-key-here"
base_url = "https://api.deepseek.com/v1"
model = "deepseek-chat"
