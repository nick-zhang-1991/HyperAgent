Command Reference

CLI Commands

CommandDescription
hyper run <prompt>Run a coding task (reads from stdin if no prompt)
hyper initBuild code index for the current project
hyper review <ref>Review code changes from git diff
hyper eval --task <name>Run a benchmark task
hyper eval --listList available benchmark tasks
hyper auth loginConfigure LLM provider credentials
hyper auth statusShow current auth state
hyper kanbanView kanban board
hyper diffShow changes from the last run
hyper mcp-serverStart MCP server for tool composability
hyper scheduleManage scheduled cron jobs
hyper checkpointSnapshot-based undo system
