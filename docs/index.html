Why HyperAgent?

⚡ N-way Parallel

Run 3+ coding agents simultaneously. Each agent works independently on different files — the only CLI agent with true parallel execution.

🔀 Multi-Provider

Route between DeepSeek, OpenAI, Anthropic, OpenRouter. Automatic failover with circuit breaker and cooldown.

🧠 Persistent Memory

SQLite-backed memory that persists across sessions. Learns from past conversations. Export/share across projects.

🔍 PageRank Index

4-strategy code indexer (import graph, symbol search, entity extraction, TF-IDF). Finds the right file instantly.

🏢 Enterprise Ready

Organization management, RBAC, OIDC, audit logging, budget tracking, per-session cost control.

🔌 Plugin System

Extend with custom tools via `.hyper/plugins/`. MCP protocol support for composable agent workflows.

🚀 Quick Install

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/nick-zhang-1991/HyperAgent/master/scripts/install.sh | bash

# Or download from GitHub Releases
# https://github.com/nick-zhang-1991/HyperAgent/releases

# Start the REPL
hyper

# Or run a single task
hyper run "Explain this codebase"

# List all commands
hyper help

📦 npm (experimental)

npm install -g hyperagent-cli
hyper
