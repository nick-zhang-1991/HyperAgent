# HyperAgent CLI

```bash
npx @hyperagent/cli run "your task"
```

[![npm](https://img.shields.io/npm/v/@hyperagent/cli?style=flat-square)](https://www.npmjs.com/package/@hyperagent/cli)
[![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)

The npm package for [HyperAgent](https://github.com/nick-zhang-1991/HyperAgent) — an ultra-fast CLI coding agent with multi-agent parallelism, persistent memory, and automatic LLM failover.

## Usage

```bash
# Run a coding task
npx @hyperagent/cli run "add rate limiting to API gateway"

# Interactive REPL
npx @hyperagent/cli

# Or install globally
npm install -g @hyperagent/cli
hyper run "your task"
```
