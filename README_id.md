## Install

```bash
export HYPER_LANG=id
brew install nick-zhang-1991/hyperagent/hyperagent
```

```bash
hyper run "tugas"
hyper analyze
hyper swarm "complex task"
```

All CLI output auto-detects your language from `HYPER_LANG=id`.
