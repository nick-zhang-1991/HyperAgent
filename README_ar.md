## Install

```bash
export HYPER_LANG=ar
brew install nick-zhang-1991/hyperagent/hyperagent
```

```bash
hyper run "مهمة"
hyper analyze
hyper swarm "complex task"
```

All CLI output auto-detects your language from `HYPER_LANG=ar`.
