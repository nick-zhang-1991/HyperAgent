# HyperAgent 🚀

**Vietnamese / Tiếng Việt**

[English](README.md) | [中文](README_zh-CN.md) | **vi**

## Install

```bash
export HYPER_LANG=vi
brew install nick-zhang-1991/hyperagent/hyperagent
```

```bash
hyper run "nhiệm vụ"
hyper analyze
hyper swarm "complex task"
```

All CLI output auto-detects your language from `HYPER_LANG=vi`.

Full documentation: [English README](README.md)
