## Install

```bash
export HYPER_LANG=fr
brew install nick-zhang-1991/hyperagent/hyperagent
```

```bash
hyper run "tâche"
hyper analyze
hyper swarm "complex task"
```

All CLI output auto-detects your language from `HYPER_LANG=fr`.
