## Install

```bash
export HYPER_LANG=tr
brew install nick-zhang-1991/hyperagent/hyperagent
```

```bash
hyper run "görev"
hyper analyze
hyper swarm "complex task"
```

All CLI output auto-detects your language from `HYPER_LANG=tr`.
